# 🌍  Conecta Mundos

> *"Cada gesto conta. Comece agora."*

O **Conecta Mundos** é uma plataforma web desenvolvida para aproximar pessoas dispostas a ajudar — seja com tempo, recursos ou habilidades — de Organizações Não Governamentais (ONGs) verificadas que geram impacto social real em comunidades por todo o Brasil.

---

## 📋 Sobre o Projeto

Muitas pessoas desejam contribuir com causas sociais, mas não sabem onde encontrar instituições confiáveis ou como iniciar. O **Conecta Mundos** resolve esse problema oferecendo uma vitrine intuitiva, moderna e acessível onde usuários podem explorar diferentes áreas de atuação, conhecer o trabalho de ONGs cadastradas e se voluntariar de forma simples e segura.

### ✨ Funcionalidades

- **Navegação Intuitiva:** Barra de navegação prática e rolagem fluida entre as seções da página.
- **Exploração por Causas:** Categorização visual das principais frentes sociais:
  - 📚 Educação
  - 🏥 Saúde
  - 🌱 Meio Ambiente
  - 🏠 Moradia
  - ⚖️ Direitos Humanos
  - 🎭 Cultura
  - 🍲 Alimentação
  - 🐾 Animais
- **Vitrine de ONGs Verificadas:** Cards informativos destacando a missão e a área de impacto de cada organização.
- **Área de Acesso e Cadastro:** Fluxos dedicados para login de voluntários (`login-pessoa.html`) e cadastro de novas instituições (`cadastro-ong.html`).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica das seções e formulários.
- **CSS3:** Estilização moderna utilizando *Flexbox* e gradientes personalizados.
- **JavaScript (Vanilla):** Interatividade e controle de eventos da interface.
